# 5–10 minute demo guide

1. Run `streamlit run app.py` and open Home; introduce the safety and optional LLM design.
2. In Resume Analysis upload a fictional student PDF, then paste the sample Data Analyst job description.
3. Show extracted fields, then Job Matching score and evidence.
4. Open Skill Gap and Career Roadmap; explain strong/partial/missing categories.
5. Generate Resume Improvement recommendations and show the no-fabrication warning.
6. Run Interview Preparation and submit a response in Mock Interview.
7. Ask the RAG Assistant about STAR answers; open the retrieved source.
8. Compare zero-shot and few-shot prompts in Prompt Evaluation and discuss evaluation limitations.
